# PocketSmart

PocketSmart adalah aplikasi web pengelola keuangan pribadi yang ringan, cepat, dan intuitif. Dirancang untuk membantu pengguna mencatat pemasukan, pengeluaran, serta memantau saldo secara real-time langsung dari perangkat mobile maupun desktop.

## Fitur Utama
- **Pencatatan Keuangan:** Tambah, edit, dan pantau catatan transaksi masuk serta keluar dengan mudah.
- **Ringkasan Saldo Otomatis:** Perhitungan total saldo, total pemasukan, dan total pengeluaran secara langsung.
- **Penyimpanan Lokal (Local Storage):** Data transaksi tersimpan aman di dalam browser pengguna tanpa memerlukan server eksternal yang rumit.
- **Multi-Platform:** Dibangun menggunakan teknologi web standar (HTML, CSS, JavaScript) dan dapat dibungkus menjadi aplikasi Android native menggunakan Capacitor.

## Teknologi yang Digunakan
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Mobile Wrapper:** CapacitorJS
- **Build Tool:** Gradle

## Cara Menjalankan Project (Development)
1. Clone repository ini ke komputer lokal:
git clone https://github.com/cutzhraa/pocketsmart.git

2. Masuk ke direktori project dan buka file `index.html` menggunakan browser atau jalankan melalui live server.
